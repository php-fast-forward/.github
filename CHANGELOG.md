# Changelog

Notable changes to the PHP Fast Forward organization profile and brand kit.

The historical versions below are assigned retrospectively to reviewed mainline
milestones. Dates identify the source commits, not an assertion that GitHub
Releases were published on those dates. Pending contributions stay in
`.changelog/`; the existing automated version workflow owns their next release.

## [0.3.0] - 2026-10-20

### Added

- Add separate developer and editorial Dash model/expression studies, dedicated avatar and favicon exports, and explicit visual-review and artwork-rights records. ([#14](https://github.com/php-fast-forward/.github/pull/14))

### Changed

- Adopt Fast Forward Changelog automation and its project skill for validated contribution notes and reviewed version pull requests. ([#12](https://github.com/php-fast-forward/.github/pull/12))
- Restore the Changelog skill from its GitHub source during Composer installation instead of committing a generated copy and separate installation receipt. ([#12](https://github.com/php-fast-forward/.github/pull/12))

## [0.2.0] - 2026-10-05

### Added

- Establish Dash's primary developer and secondary editorial collections, selected pose references, a native fox signature with orange “Fast”, monochrome variants and outlined Exo 2 Italic lettering. ([#7](https://github.com/php-fast-forward/.github/pull/7))
- Define the visual system, brand voice and character in `DESIGN.md`, `STYLE.md` and `SOUL.md`, with tokens, asset provenance, artwork receipts and the portable Dash artwork skill. ([#7](https://github.com/php-fast-forward/.github/pull/7))
- Provide brand, logo, documentation and contextual ecosystem specimens with GitHub Pages publication, PHP export/validation tooling and regression tests. ([#7](https://github.com/php-fast-forward/.github/pull/7))
- Add shared community policies and English, Portuguese and Spanish profile/readme surfaces. ([#7](https://github.com/php-fast-forward/.github/pull/7))

### Changed

- Replace active profile artwork with the selected identity, classify historical sources separately and document package-specific artwork delivery. ([#7](https://github.com/php-fast-forward/.github/pull/7))

### Fixed

- Remove committed Finder metadata and ignore local operating-system files. ([#7](https://github.com/php-fast-forward/.github/pull/7))

## [0.1.1] - 2026-04-24

### Changed

- Include the Enum library in the organization profile manifesto. ([#1](https://github.com/php-fast-forward/.github/pull/1))

## [0.1.0] - 2026-04-23

### Added

- Create the public organization profile, framework/mascot artwork, package badges, funding metadata and repository README.
- Add profile hero/banner and footer compositions.

### Fixed

- Correct SVG artwork transparency, badge links and underline spacing.
- Refine image alignment, cropping and responsive sizing in the profile.
