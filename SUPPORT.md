# Getting help with PHP Fast Forward

These are organization defaults. Follow the affected repository's own support instructions when present.

For framework behavior, installation, or a specific `fast-forward/*` package, search and ask in the affected package repository. Include the package and PHP versions, the command or minimal example, the expected result, and the actual result. File implementation changes and bug reports there.

For the organization profile, visual identity, mascot, or reusable design assets, use the [profile and design repository](https://github.com/php-fast-forward/.github). Read [DESIGN.md](https://github.com/php-fast-forward/.github/blob/main/DESIGN.md) and [the asset guide](https://github.com/php-fast-forward/.github/blob/main/assets/README.md) before asking about asset use. Describe the intended audience and surface, required format or dimensions, and the existing asset or public reference involved.

Keep examples suitable for public reading. Remove credentials, personal information, private URLs, and confidential material. Follow the affected repository's security policy, or the [shared security guidance](https://github.com/php-fast-forward/.github/blob/main/SECURITY.md), for potential vulnerabilities. Use the [Code of Conduct](https://github.com/php-fast-forward/.github/blob/main/CODE_OF_CONDUCT.md) for conduct concerns.

Use the GitHub channels that the affected repository actually provides. These defaults do not advertise a private support address or a guaranteed response time.
