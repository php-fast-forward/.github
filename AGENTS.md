# PHP Fast Forward brand kit

This repository owns the public organization profile, visual identity, assets
and PHP brand publication tooling. Read DESIGN.md, SOUL.md, STYLE.md and
assets/README.md before changing artwork or identity contracts. Keep generation,
visual review, maintainer selection, licensing and publication distinct.

## Bundled consumer skill

Read [fast-forward-dash-art](resources/skills/fast-forward-dash-art/SKILL.md)
for repository artwork tasks and when changing the consumer procedure,
installation guide or examples. Its canonical source is resources/skills;
project .agents/skills contains consumed installer-managed skills, not another
published copy. Keep the skill's version contract and complete licensed payload
aligned with the actual kit. Use [the installation guide](docs/brand/skill-installation.md)
for optional consumer setup.

## Validation and changes

Use the supported PHP/Composer toolchain and run composer check.
Build the public preview with composer build:pages when publication inputs or
links change. Use the kit's PHP generators for reproducible exports; preserve
unknown source rights and unrelated work. Consumer repository assets need their
own scoped PR. Root instructions govern maintenance; the skill owns its portable
consumer procedure. No child instruction scope or host alias is required.
