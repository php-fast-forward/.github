# Visual references

These files help compare the character and plan future surfaces. They are not
the token source or a promise of shipped features. The
[asset manifest](../assets/manifest.json) records their origin and status.

- Archived website concepts: supplied landing and documentation studies remain
  in the ignored local archive and `archived_sources` metadata, outside the
  visible brand kit. Layout and atmosphere informed the patterns; versions,
  statistics, APIs, social destinations, dependencies, and license footers remain
  unverified concept copy.
- `ecosystem/`: nineteen reviewed contextual Dash illustrations, copied exactly
  from the consumer repositories' `docs/_static/mascot-banner.png` files. Each
  manifest record pins the source commit, image hash, dimensions and central
  generation receipt. The developer welcome/build references govern the
  character; these scenes demonstrate repository-specific applications. The
  original thirteen banners were retired on 2026-10-05 with their source IDs,
  provenance and bytes preserved in the ignored local archive. The earlier
  `framework` banner remains in its 2026-10-03 archive entry.
- `icons/`: archived icon collection/sprite for reference. These SVGs contain
  vector geometry, but third-party marks and authorship have no recorded usage
  rights. The sprite CSS now points to the actual `icon_sprite.png` filename;
  that repair is recorded as a derivative. Prefer accessible labeled icons from
  a documented source when implementing a production interface.

The 2026-10-03 audit inspected 19 local image paths / 16 distinct contents.
Fourteen historical package illustrations were curated and are now archived;
their public pins, local-source distinctions and visual deviations remain in
the manifest's `archived_sources`. Ignored generated duplicates and older
divergent renderings were not imported. The original cute source-pack
exports are archived in the ignored local `backup/dash/legacy-kit/`. Newly
created Dash reference collections live in `assets/mascot/` instead.

Logo direction F was selected from the local comparison: a fox signature with
orange “Fast” and monochrome of the same geometry. The generated comparison
image records exploration; it is not a vector master. The current production
source is [logo-source.json](../assets/brand/logo-source.json), with eight SVGs
described in the [asset guide](../assets/README.md#logo-masters). The official
[Exo 2 source record](../assets/brand/source/font-source.json) establishes the
selected lettering's provenance; it does not identify or license legacy fonts
and artwork.

The [contextual artwork catalog](../docs/brand/repository-artwork.json) keeps the
nineteen exact prompts, canonical input hashes, output receipts and consumer
source commits centrally. Consumer repositories use a relative README image
path and exclude `/docs/` and `/README*.md` from package archives. Generation
receipts stay in this identity repository.
